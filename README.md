## Lançamento

A landing conta os dias até **1º de dezembro de 2026, 00h de Brasília**
(`LANCAMENTO`, no topo de `script.js`). Até lá, o botão principal leva ao
Instagram [@lumibiblia](https://www.instagram.com/lumibiblia/); a partir da
data, a página troca sozinha para o link da Play Store — sem novo deploy.

O que aparece em cada fase é marcado no HTML: `.so-antes` e `.so-depois`.
Para adiar o lançamento, mude só a data em `script.js`.

As regras da marca neste repositório — cores, tipografia, o personagem e o
checklist de página nova — estão em [`MARCA.md`](MARCA.md).
